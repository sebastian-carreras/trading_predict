🏗️ MLOps architecture

🔎 Per-ticker drilldown

Each champion is compared against a fixed baseline (linear regression for E1) that acts as a sanity floor and is never promoted. Promotion requires beating the incumbent by ≥5% on a composite score (0.35·Sharpe + 0.25·IC + 0.20·DirAcc + 0.20·Calmar).

The system monitors whether champions degrade over time (concept drift) and whether the feature distribution shifts vs training (data drift, via KS/PSI tests in src/lifecycle/drift.py).

Honest, leakage-aware validation

  • Walk-forward CV with embargo (≥ prediction horizon) between train and test — never evaluated on information the model couldn't have had.
  • Z-score computed on the train fold only (stats never see val/test → no data snooping).
  • Huber loss (robust to price outliers), not MSE.
  • Registry as single source of truth, atomic writes, champion/challenger promotion with guardrails (reject NaN/Inf, Sharpe < 0, IC worse than baseline).
